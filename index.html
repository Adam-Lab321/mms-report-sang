Файлы не выбраны

Можно прикрепить готовый .doc / .html (уйдёт как есть). Без файла — отчёт соберётся из таблицы рапорта. Разрешены: Word, HTML, JSON, картинки, PDF (до 8 МБ). Исполняемые файлы и архивы не принимаются.

📋 КАК ПРАВИЛЬНО СДАТЬ РАПОРТ
  1. Заполни карточку — ФИО и Static ID.
  2. Добавь записи в рапорт (доказательства и записи).
  3. Вкладка «Сдача в Discord»: выбери тип (еженедельный / повышение).
  4. Нажми «Предпросмотр» (рекомендуется) и проверь рапорт.
  5. Нажми «Отправить в Discord» — уйдёт один Word-файл (.doc) и краткое описание (кто, дата, баллы).
Проверяющие открывают вложение в Word. В сообщении Discord всегда видно: сотрудник, ID, дата и баллы — даже если имя файла обрезано.
Учёт сдачи MMS
При отправке фиксируются служебные данные для учёта подразделения: время, тип рапорта, ID сотрудника, лицензия (если активна), результат доставки. Пароли не сохраняются. Данные видит только командование MMS, третьим лицам они не передаются.
Канал: еженедельный рапорт · ping @Руководство MMS
